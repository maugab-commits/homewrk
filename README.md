# homewrk

A PowerPoint alternative focused on productivity and study, designed to create, organize, and present content efficiently.

Live Demo: [https://homewrk-496866519434.us-east1.run.app](https://homewrk-496866519434.us-east1.run.app)
## Key Features

- Study-Focused: Built as a support tool for summaries, quick reviews, and streamlined presentations.

- Modern Web Interface: Powered by current web technologies for a smooth browser experience.

- Typed Architecture: Developed primarily in TypeScript for easier maintenance and scalability.

## Tech Stack

- TypeScript (98.4%)

- Vite (development server and bundler)

- CSS / HTML

## Project Structure

- homewrk/
  - src/ (Main application source code)
  - index.html (HTML entry point)
  - metadata.json (Project metadata)
  - package.json (Dependencies and scripts)
  - tsconfig.json (TypeScript configuration)
  - vite.config.ts (Vite configuration)

## Local Setup & Installation

1. Clone the repository:
git clone https://github.com/maugab-commits/homewrk.git
cd homewrk
2. Install dependencies:
npm install
3. Configure environment variables (if applicable):
If the application requires API keys (such as GEMINI_API_KEY), create a .env.local file in the root directory with the required variables.
4. Start the development server:
npm run dev
